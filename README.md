# Mega Moodle

Versão inicial em linha de comando que implementa um único caso de uso:
**cadastrar disciplina**.

## Executar

Com o `uv` instalado, execute:

```bash
uv run mega-moodle
```

O menu permite cadastrar várias disciplinas e listar todas elas. As disciplinas
existem somente durante a execução do programa, pois esta versão não utiliza
banco de dados.
